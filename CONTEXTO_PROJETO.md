# Contexto do Projeto: Video Anchor

Este documento serve como guia de continuidade para que uma IA ou desenvolvedor entenda o estado atual do projeto e os próximos passos.

## 🎯 Objetivo do Projeto
O Video Anchor é uma ferramenta de produção de vídeos publicitários (VSLs e Criativos) usando avatares de IA com lip-sync realista para a agência The Anchor.

## 🏗️ Arquitetura Técnica
- **Stack:** Node.js + FFmpeg + ElevenLabs (Áudio) + D-ID API (Lip-sync).
- **Processo:** Roteiro → Narração → Geração de Avatar → Lip-sync → Edição Final.
- **Diferencial:** Avatares que olham diretamente para a câmera, cenários ricos e legendas dinâmicas.

## ✅ O que já foi implementado (Últimas Atualizações)
1. **Lip-sync Realista:** Integração com a API do D-ID para sincronia labial perfeita nos vídeos finais.
2. **Qualidade Visual:** Avatares configurados para olhar diretamente para a lente, aumentando a conexão com o espectador.
3. **Análise de Performance:** Sistema que avalia a copy dos roteiros antes da produção.
4. **CTA Groover:** Inclusão de legendas e chamadas para ação estilizadas.

## 🚀 Próximos Passos (Pendências)
1. **Automação de Background:** Implementar fila de processamento para renderização de vídeos longos.
2. **Novos Templates:** Criar variações de cenários (escritório, lifestyle, estúdio) para diferentes nichos.
3. **Integração de Exportação:** Opção de enviar o vídeo final diretamente para o Google Drive ou Dropbox do cliente.
